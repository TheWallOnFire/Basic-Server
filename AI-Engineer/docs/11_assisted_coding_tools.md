# 11. Assisted Coding Tools

The way we build software is changing. AI is now a core part of the developer workflow.

## 1. The Big Players
- **GitHub Copilot**: The industry standard autocomplete and chat tool.
- **Cursor**: An AI-native code editor (fork of VS Code) with deep model integration.
- **Windsurf**: The first "agentic" IDE from Codeium.

## 2. "Vibe Coding" & Flow
"Vibe Coding" is a humorous term for a real shift: developers focus more on high-level intent and "vibes" (natural language) while the AI handles the boilerplate and complex syntax.
- **Intent-based coding**: "Build me a login page with JWT".
- **Refactoring**: "Explain and simplify this complex function".
- **Documentation**: "Write docstrings for this entire file".

## 3. Best Practices
- **Human-in-the-loop**: Never blindly trust AI-generated code. Review every change.
- **Context Management**: Give the AI the right files and documentation to work with.
- **Security**: Be careful about pasting sensitive secrets into AI prompts.
