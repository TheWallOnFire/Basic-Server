# 13. Data Science Foundations

The mathematical and practical foundations that every AI Engineer should understand, even if they don't build models from scratch.

## 1. Mathematics for AI
### Linear Algebra
- **Vectors & Matrices**: The language of data (embeddings are vectors!).
- **Matrix Multiplication**: How neural network layers transform data.
- **Eigenvalues & Eigenvectors**: Foundations of PCA and dimensionality reduction.

### Statistics & Probability
- **Distributions**: Normal, Bernoulli, Poisson — understanding data shape.
- **Bayes' Theorem**: The foundation of probabilistic reasoning.
- **Hypothesis Testing**: p-values, confidence intervals, A/B testing.
- **Correlation vs. Causation**: A critical distinction.

### Calculus
- **Gradient Descent**: How models learn by minimizing loss.
- **Partial Derivatives**: Backpropagation in neural networks.

## 2. Data Wrangling
- **Pandas**: The Python library for tabular data manipulation.
- **NumPy**: Numerical computing with arrays and matrices.
- **Data Cleaning**: Handling missing values, outliers, and duplicates.
- **Feature Scaling**: Normalization vs. Standardization.

## 3. Data Visualization
- **Matplotlib / Seaborn**: Static charts and statistical plots.
- **Plotly**: Interactive, web-ready visualizations.
- **Key Charts**: Histograms, scatter plots, box plots, heatmaps, confusion matrices.

## 4. Classical ML Algorithms
| Algorithm | Type | Use Case |
| :--- | :--- | :--- |
| **Linear Regression** | Regression | Predicting continuous values |
| **Logistic Regression** | Classification | Binary outcomes |
| **Decision Trees** | Both | Interpretable predictions |
| **Random Forest** | Both | Ensemble of decision trees |
| **SVM** | Classification | High-dimensional data |
| **K-Means** | Clustering | Grouping similar data |
| **KNN** | Classification | Instance-based learning |
| **XGBoost** | Both | Competition-winning gradient boosting |

## 5. Deep Learning Architectures
- **CNNs (Convolutional Neural Networks)**: Image recognition.
- **RNNs / LSTMs**: Sequential data (text, time-series).
- **Transformers**: The architecture behind modern LLMs (GPT, BERT).
- **GANs**: Generative Adversarial Networks for data generation.

## 6. Evaluation Metrics
| Metric | Use Case |
| :--- | :--- |
| **Accuracy** | Balanced classes |
| **Precision / Recall** | Imbalanced classes (fraud, medical) |
| **F1 Score** | Harmonic mean of precision and recall |
| **AUC-ROC** | Classification threshold analysis |
| **MSE / RMSE / MAE** | Regression error measurement |
| **BLEU / ROUGE** | NLP text generation quality |

## 7. Tools & Frameworks
- **Scikit-learn**: Classical ML in Python.
- **PyTorch**: The researcher's deep learning framework.
- **TensorFlow / Keras**: Production-grade deep learning.
- **Hugging Face**: Pre-trained models and datasets hub.
- **Jupyter Notebooks**: Interactive experimentation.
