# 01. AI Engineer Introduction

An AI Engineer uses pre-trained models and existing AI tools to improve user experiences. They focus on applying AI in practical ways, without necessarily building models from scratch.

## 1. What is an AI Engineer?
- **Goal**: Apply AI to solve real-world problems.
- **Focus**: Integration, prompt engineering, RAG, and agentic workflows.
- **Tools**: LLMs (GPT, Claude), APIs, Frameworks (LangChain, LlamaIndex).

## 2. AI Engineer vs. ML Engineer
| Feature | AI Engineer | ML Engineer |
| :--- | :--- | :--- |
| **Model Creation** | Uses existing models | Builds/Trains models |
| **Data Focus** | Context & Prompts | Datasets & Training |
| **Skills** | Software Eng + AI APIs | Math, Stats, ML Ops |

## 3. Core Terminology
- **LLM**: Large Language Model.
- **AGI**: Artificial General Intelligence (human-level AI).
- **Inference**: Running a model to get an output.
- **Fine-tuning**: Adjusting a pre-trained model on a smaller, specific dataset.
- **Hallucination**: When a model generates factually incorrect information.
