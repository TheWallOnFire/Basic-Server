# 04. AI Models & Platforms

Choosing the right model is a balance between performance, cost, and latency.

## 1. Proprietary Models (Closed Source)
- **OpenAI**: GPT-4o, GPT-4o-mini, o1.
- **Anthropic**: Claude 3.5 Sonnet/Haiku/Opus.
- **Google**: Gemini 1.5 Pro/Flash.

## 2. Open Source / Open Weight Models
- **Meta**: Llama 3.1 / 3.2.
- **Mistral AI**: Mistral 7B, Mixtral 8x7B, Pixtral.
- **DeepSeek**: DeepSeek-V3, DeepSeek-Coder.

## 3. Deployment Platforms
- **API First**: OpenAI, Anthropic, Gemini, Groq (ultra-fast).
- **Self-Hosting**: Ollama (local), vLLM, Hugging Face TGI.
- **Cloud Providers**: AWS Bedrock, Google Vertex AI, Azure AI Studio.
