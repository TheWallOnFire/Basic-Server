# Creative & Brainstorming Prompts

Real-world, copy-paste-ready prompts for brainstorming and creative tasks. Each shows a ❌ weak prompt and a ✅ strong prompt.

---

## Example 1 — Brainstorm Features

❌ **Weak Prompt**:
```
Give me ideas for my app.
```

✅ **Strong Prompt**:
```
I'm building a developer productivity tool that tracks coding time 
(similar to WakaTime). I have 500 beta users.

Brainstorm 10 feature ideas for the next release. For each idea:

| # | Feature Name | Description (1 sentence) | Effort (S/M/L) | Impact (1-5) | Priority Score |

Categorize them into:
- 🎯 Retention features (keep existing users engaged)
- 📈 Growth features (attract new users)
- 💰 Monetization features (convert free to paid)

Rank by Priority Score = Impact × (1/Effort), where S=1, M=2, L=3.

Constraints:
- I'm a solo developer, so no features requiring a dedicated team
- Must work offline-first (users care about privacy)
- No AI/ML features (keep it simple)

End with your top 3 recommendation and a suggested 3-month roadmap.
```

## Example 2 — Name Things

❌ **Weak Prompt**:
```
Name my project.
```

✅ **Strong Prompt**:
```
Generate 15 name ideas for an open-source CLI tool that:
- Converts natural language to shell commands
- Supports bash, zsh, PowerShell
- Runs locally (privacy-first, no cloud)

Requirements for names:
- Max 10 characters
- Easy to type in a terminal
- Available as an npm package name (check naming conventions)
- Not a common English word (to avoid conflicts)
- Evokes "translation" or "intelligence" or "command"

For each name, provide:
| Name | Why It Works | Possible Logo Concept |

Highlight your top 3 picks.
```
