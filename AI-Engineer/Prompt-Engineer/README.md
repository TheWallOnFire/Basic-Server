# ✍️ Prompt Engineering

Prompt Engineering is the art and science of designing effective instructions for AI models to produce the best possible output. It is the **single most impactful skill** an AI Engineer can master — it costs nothing, requires no training data, and can dramatically improve model performance.

## 🚀 Quick Start

The fastest way to become a better prompter:

1. **Read** the [Anatomy of a Prompt](./docs/02_anatomy_of_a_prompt.md) to understand the building blocks.
2. **Practice** the [Core Techniques](./docs/03_core_techniques.md) with any model (ChatGPT, Claude, Gemini, Ollama).
3. **Apply** the [Prompt Patterns](./docs/07_prompt_patterns_templates.md) to your real-world tasks.

---

## 💡 Key Principle

> **A prompt is not a question — it is a program.** The more precisely you define the input format, reasoning steps, constraints, and output format, the more reliable and useful the model's response will be.
