# Database Learning Resources

Whether you are a beginner looking to understand basic SQL or an advanced developer diving into distributed systems, these resources will help you master databases.

## 1. Interactive Tutorials (Beginner)
- **[SQLBolt](https://sqlbolt.com/)**: A series of interactive lessons and exercises designed to help you quickly learn SQL right in your browser.
- **[Select Star SQL](https://selectstarsql.com/)**: An interactive book that aims to be the best place on the internet for learning SQL.
- **[MongoDB University](https://university.mongodb.com/)**: Free, official courses provided by MongoDB to learn everything from basics to advanced administration.

## 2. Books (Intermediate to Advanced)
- **Designing Data-Intensive Applications** by Martin Kleppmann. 
  *(The absolute gold standard book for understanding how modern databases, caching, and distributed systems work under the hood. Highly recommended for any backend engineer).*
- **SQL Antipatterns** by Bill Karwin.
  *(A great book for learning what NOT to do when designing relational databases).*
- **Seven Databases in Seven Weeks** by Luc Perkins, Eric Redmond, and Jim R. Wilson.
  *(A hands-on guide exploring PostgreSQL, Riak, Apache HBase, MongoDB, CouchDB, Neo4J, and Redis).*

## 3. Advanced Concepts & Documentation
- **[Use The Index, Luke!](https://use-the-index-luke.com/)**: A fantastic guide to database performance for developers. It explains exactly how indexes work across various SQL databases.
- **[PostgreSQL Official Tutorial](https://www.postgresql.org/docs/current/tutorial.html)**: The official docs are incredibly well-written and thorough.
- **[Jepsen Analyses](https://jepsen.io/analyses)**: For advanced distributed systems engineering. Jepsen tests the safety guarantees of distributed databases under network partitions.

## 4. YouTube Channels
- **Hussein Nasser**: An excellent channel focusing on backend engineering, database architectures, proxies, and network protocols.
- **ByteByteGo (Alex Xu)**: Visual explanations of complex system design concepts, including database scaling and replication.
