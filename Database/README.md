# Database & Storage Pillar

This section covers data storage, management, and abstraction layers for modern applications.

## 🗃️ Categories

### 1. [Relational (SQL)](./Relational/)
Structured data storage with ACID compliance: PostgreSQL, MySQL, SQLite.

### 2. [NoSQL](./NoSQL/)
Flexible data models: MongoDB (Document), Redis (Key-Value), Cassandra (Wide-Column), ClickHouse (Analytical).

### 3. [ORM & Query Builders](./ORM%20&%20Query%20Builders/)
Object-Relational Mapping tools to interact with databases via code: Prisma, Drizzle, Sequelize, Mongoose.

### 4. [Management Tools](./Management%20Tools/)
GUIs and CLI tools for database administration: pgAdmin, DBeaver, MongoDB Compass.

### 5. [Cloud & BaaS](./Cloud%20&%20BaaS/)
Managed database services: Supabase, Firebase, PlanetScale.
