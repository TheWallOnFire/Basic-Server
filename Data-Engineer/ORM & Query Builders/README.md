# ORM & Query Builders

## Overview
These tools provide an abstraction layer between your application code and the database, making it easier to manage data models and perform queries.

## Tools in this Category
- **[Prisma](./Prisma/)**: Modern, type-safe ORM for Node.js/TypeScript.
- **[Sequelize](./Sequelize/)**: Mature, promise-based ORM for Node.js.
- **[Drizzle](./Drizzle/)**: Ultra-lightweight, type-safe ORM for TypeScript.
- **[Mongoose](./Mongoose/)**: Document modeling for MongoDB.
- **[Knex](./Knex/)**: Flexible SQL Query Builder for Node.js.

## Comparison
| Feature | Prisma | Sequelize | Drizzle |
| :--- | :--- | :--- | :--- |
| **Type Safety** | High (Auto-generated) | Medium | High (Schema-first) |
| **Migration** | Built-in | Built-in | External |
| **Performance** | Good | Moderate | Excellent |
| **Learning Curve**| Low | Medium | Low-Medium |
