# Cloud Databases & BaaS

## Overview
Managed database services and Backend-as-a-Service (BaaS) platforms that handle infrastructure for you.

## Tools in this Category
- **[Supabase](./Supabase/)**: Open-source Firebase alternative (PostgreSQL-based).
- **[Firebase](./Firebase/)**: Google's mobile/web platform (Firestore).
- **[PlanetScale](./PlanetScale/)**: Serverless MySQL platform.
- **[MongoDB Atlas](./MongoDB%20Atlas/)**: Managed MongoDB service.

## Why use Cloud/BaaS?
- **Zero Maintenance**: No need to worry about patching or hardware.
- **Auto-Scaling**: Scales up/down based on traffic.
- **Built-in Features**: Often includes Auth, Storage, and Real-time sync.
