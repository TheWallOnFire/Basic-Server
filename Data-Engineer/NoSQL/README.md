# NoSQL Databases

## Overview
NoSQL databases are non-tabular and store data differently than relational tables. They are designed for high-scale, high-velocity, and diverse data types.

## Tools in this Category
- **[MongoDB](./MongoDB/)**: Document-oriented (JSON-like).
- **[Redis](./Redis/)**: In-memory key-value store (Caching/Messaging).
- **[Cassandra](./Cassandra/)**: Wide-column store for massive scale.
- **[Elasticsearch](./Elasticsearch/)**: Search engine and document store.
- **[Neo4j](./Neo4j/)**: Graph database for complex relationships.
- **[InfluxDB](./InfluxDB/)**: Time-series database for metrics/IoT.
- **[ClickHouse](./ClickHouse/)**: Analytical columnar database for big data.

## When to use which?
- **MongoDB**: Content management, flexible schemas.
- **Redis**: Caching, real-time analytics, session management.
- **Cassandra**: Global scale, write-heavy workloads.
- **Neo4j**: Social networks, recommendation engines, fraud detection.
