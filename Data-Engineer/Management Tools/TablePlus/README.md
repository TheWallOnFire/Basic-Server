# TablePlus

## Description
TablePlus is a modern, lightweight, native database management GUI tool. It supports a wide range of databases and is known for its clean, fast interface and intuitive user experience.

## Key Features
- Sleek, native UI (not Electron — very fast and responsive)
- Multi-tab, multi-window database management
- Inline data editing (click and edit cells directly)
- Smart query editor with autocomplete
- SSH tunneling and SSL support
- Code review mode (preview SQL changes before committing)
- Supports plugins and themes (including dark mode)

## How to Install
Download from https://tableplus.com/ — available for macOS, Windows, Linux, and iOS.

## Supported Databases
PostgreSQL, MySQL, MariaDB, SQLite, Redis, MongoDB, Cassandra, CockroachDB, SQL Server, Oracle, and more.

## When to Use
- You want a fast, native desktop client (not a web-based or Electron tool)
- You work across multiple database types daily
- You want to visually edit data inline without writing UPDATE statements
- You want a beautiful, modern alternative to pgAdmin or MySQL Workbench
