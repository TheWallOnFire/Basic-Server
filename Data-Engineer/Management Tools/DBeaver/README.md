# DBeaver

## Description
DBeaver is a free, cross-platform, universal database tool for developers and database administrators. It supports virtually every database through JDBC drivers.

## Key Features
- Supports 100+ databases (PostgreSQL, MySQL, MongoDB, Redis, SQLite, Oracle, etc.)
- Visual SQL editor with autocomplete and formatting
- ER diagram generation from existing schemas
- Data transfer between different databases
- SSH tunneling for remote database access
- Dark mode and customizable UI

## How to Install
Download from https://dbeaver.io/download/ — available for Windows, macOS, and Linux.

```bash
# Or via Chocolatey (Windows)
choco install dbeaver

# Or via Homebrew (macOS)
brew install --cask dbeaver-community
```

## When to Use
- You work with **multiple database types** and want one tool for all of them
- You need visual ER diagrams of your schema
- You want to transfer data between databases
- You prefer a desktop application over a web-based tool
