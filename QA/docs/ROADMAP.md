# 🗺️ QA Engineer Roadmap

Welcome to the QA Engineer Roadmap! This guide is based on the [roadmap.sh/qa](https://roadmap.sh/qa) and is designed to take you from understanding testing basics to building robust, automated quality pipelines.

---

## 🛤️ The Path

### 🟢 Phase 1: Foundations
1. **[QA Fundamentals](./01_qa_fundamentals.md)**: QA role, SDLC, testing levels (Unit/Integration/E2E), and the Testing Pyramid.
2. **[Manual Testing](./02_manual_testing.md)**: Writing test cases, test plans, exploratory testing, and bug reporting.

### 🟡 Phase 2: Automation
3. **[Automation Testing](./03_automation_testing.md)**: Playwright, Cypress, Selenium — frameworks, patterns (POM, BDD), and best practices.
4. **[API Testing](./04_api_testing.md)**: REST & GraphQL testing, Postman, contract testing with Pact.

### 🟠 Phase 3: Specialized Testing
5. **[Performance Testing](./05_performance_testing.md)**: Load, stress, and spike testing with k6, JMeter, and Locust.
6. **[Mobile Testing](./06_mobile_testing.md)**: Appium, device farms, and mobile-specific considerations.

### 🔴 Phase 4: Pipeline & Security
7. **[CI/CD Integration](./07_cicd_integration.md)**: Test pipelines, reporting, flaky test management, and environments.
8. **[Security Testing](./08_security_testing.md)**: OWASP Top 10, SAST/DAST, and penetration testing tools.

### 📚 Phase 5: Reference
9. **[QA Tools Comparison](./09_qa_tools_comparison.md)**: Side-by-side comparison of UI, API, Performance, and Test Management tools.

---

## 🚀 Pro Tip
Start by writing **manual test cases** for a feature you know well, then automate them with **Playwright** or **Cypress**. The transition from manual to automated testing is the most valuable QA skill.
