# 🎭 Playwright E2E Starter

A modern, fast, and reliable End-to-End testing project using Playwright and TypeScript.

## 🏗️ Architecture
- **Page Object Model (POM)**: Organized page logic for maintainability.
- **Cross-Browser**: Configured to run on Chromium, Firefox, and WebKit.
- **Parallel Execution**: Blazing fast tests out of the box.
- **Reporting**: Beautiful HTML reports with screenshots and traces.

## 🛠️ Stack
- **Framework**: Playwright
- **Language**: TypeScript
- **Test Runner**: Playwright Test

## 🚀 Getting Started
1. Install dependencies: `npm install`.
2. Run tests: `npx playwright test`.
3. View report: `npx playwright show-report`.

## 🧪 Key Features
- **Auto-wait**: No more flaky `sleep()` calls.
- **Trace Viewer**: Record and inspect test failures.
- **Mobile Emulation**: Test responsive layouts easily.
