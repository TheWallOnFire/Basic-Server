# Proxies: Forward vs. Reverse

## Forward Proxy
Acts on behalf of the **client**. Used to hide the client's IP, bypass filters, or cache content for a local network.

## Reverse Proxy
Acts on behalf of the **server**. Used to:
- **Load Balancing**: Distribute traffic.
- **Security**: Hide backend server IPs.
- **SSL Termination**: Handle encryption in one place.
- **Caching**: Serve static content faster.

## Popular Tools
- **Nginx**: High-performance reverse proxy.
- **HAProxy**: High-availability load balancer.
- **Envoy**: Modern proxy for service meshes.
