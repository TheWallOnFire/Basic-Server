# Communication Protocols

## Overview
How different components of a system communicate with each other.

## Protocol Comparison

| Protocol | Model | Best For |
| :--- | :--- | :--- |
| **HTTP/REST** | Request-Response | Standard web APIs. |
| **WebSockets** | Bi-directional | Real-time chat, notifications. |
| **gRPC** | Bi-directional / Streaming | Internal microservices (high performance). |
| **GraphQL** | Query-based | Complex data requirements, frontends. |
| **WebRTC** | Peer-to-Peer | Video calls, file sharing. |
| **MQTT** | Pub/Sub | IoT, low-bandwidth devices. |
