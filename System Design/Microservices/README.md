# Microservices Architecture

## Overview
Structuring an application as a collection of loosely coupled services.

## Core Components
- **API Gateway**: Single entry point for all clients.
- **Service Discovery**: How services find each other (Consul, Eureka).
- **Service Mesh**: Managing service-to-service communication (Istio, Linkerd).
- **Circuit Breaker**: Preventing a single service failure from cascading.
- **Distributed Tracing**: Tracking requests across services (OpenTelemetry).
