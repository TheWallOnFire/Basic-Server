# Observability & Monitoring

## Overview
Observability is the ability to measure the internal state of a system by looking at its external outputs (Metrics, Logs, and Traces).

## Tools in this Category
- **[Prometheus](./Prometheus/)**: Metrics collection and alerting.
- **[Grafana](./Grafana/)**: Visualization and dashboards.
- **[Loki](./Loki/)**: Log aggregation system.
- **[ELK Stack](./ELK%20Stack/)**: Log management and analysis.
- **[OpenTelemetry](./OpenTelemetry/)**: Standard for telemetry data.
- **[Jaeger](./Jaeger/)**: Distributed tracing system.
- **[Sentry](./Sentry/)**: Error tracking and exception monitoring.
- **[PagerDuty](./Incident%20Response/)**: On-call management and incident response.
