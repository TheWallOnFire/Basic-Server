# Datadog

## Description
Datadog is a cloud-scale monitoring and security platform. It provides full-stack observability, including metrics, traces, and logs, for cloud-based applications.

## How it works
You install the Datadog Agent on your servers or as a sidecar/daemonset in Kubernetes. The agent collects data from your system and applications and sends it to the Datadog cloud platform for visualization and alerting.

## Key Capabilities
- **Infrastructure Monitoring**: Real-time metrics for servers, databases, and containers.
- **APM (Application Performance Monitoring)**: Distributed tracing to find bottlenecks in code.
- **Log Management**: Centralized log collection and analysis.
- **RUM (Real User Monitoring)**: Track the frontend performance for actual users.
- **Security**: Cloud security posture management and workload protection.

## Features
- 600+ integrations (AWS, Docker, K8s, Redis, Postgres, etc.).
- Powerful alerting with machine learning (outlier detection).
- Beautiful, highly customizable dashboards.
- Unified view of metrics, logs, and traces.
- SaaS-based (no infrastructure to manage).
