# Microsoft Azure

## Overview
Azure is Microsoft's cloud platform, providing over 200 products and cloud services designed to help you bring new solutions to life.

## Core Services Cheat Sheet

| Category | Service | Description |
| :--- | :--- | :--- |
| **Compute** | **Azure VMs** | Windows and Linux virtual machines. |
| | **Azure Functions** | Serverless event-driven functions. |
| | **App Service** | Fully managed PaaS for web apps. |
| **Containers** | **AKS** | Azure Kubernetes Service. |
| | **Container Instances** | Run containers without managing VMs. |
| **Storage** | **Blob Storage** | Object storage for unstructured data. |
| | **Azure Files** | Managed file shares (SMB/NFS). |
| **Database** | **Azure SQL** | Managed SQL Server (Best for .NET). |
| | **Cosmos DB** | Globally distributed NoSQL database. |
| **Networking** | **Virtual Network** | Isolated network in Azure. |
| | **Traffic Manager** | DNS-based load balancing. |
| **Identity** | **Entra ID** | Formerly Azure Active Directory (The gold standard). |
| **DevOps** | **Azure DevOps** | Full CI/CD, boards, and repo suite. |

## Why Azure?
- **Microsoft Integration**: Seamless integration with Windows, Office 365, and SQL Server.
- **Hybrid Cloud**: Best-in-class support for hybrid environments (Azure Arc).
- **Enterprise Ready**: Highly trusted by Fortune 500 companies.
- **Identity Management**: Entra ID is the default for corporate identity.

## Best For
- Large enterprises using the Microsoft stack (.NET, Windows).
- Organizations moving from on-premise Active Directory to the cloud.
- Hybrid cloud strategies.
