# Amazon Web Services (AWS)

## Overview
AWS is the world's most comprehensive and broadly adopted cloud platform, offering over 200 fully featured services from data centers globally.

## Core Services Cheat Sheet

| Category | Service | Description |
| :--- | :--- | :--- |
| **Compute** | **EC2** | Virtual servers in the cloud (Elastic Compute Cloud). |
| | **Lambda** | Serverless functions (run code without managing servers). |
| | **Fargate** | Serverless compute for containers (ECS/EKS). |
| **Storage** | **S3** | Scalable object storage (Simple Storage Service). |
| | **EBS** | Block storage for EC2 instances. |
| | **EFS** | Managed file system for EC2/Lambda. |
| **Database** | **RDS** | Managed relational databases (MySQL, Postgres, etc.). |
| | **DynamoDB** | High-performance NoSQL database (Key-Value/Document). |
| | **Aurora** | High-end AWS-native relational database. |
| **Networking** | **VPC** | Isolated cloud network (Virtual Private Cloud). |
| | **Route 53** | Scalable Domain Name System (DNS). |
| | **CloudFront** | Global Content Delivery Network (CDN). |
| **Security** | **IAM** | Identity and Access Management. |
| | **Secrets Manager** | Rotating and managing secrets. |
| | **KMS** | Key Management Service for encryption. |
| **Monitoring** | **CloudWatch** | Metrics, logs, and alarms. |
| | **CloudTrail** | Audit logs of every AWS API call. |

## Why AWS?
- **Maturity**: The longest-running cloud provider with the most robust service offerings.
- **Global Reach**: Available in 30+ regions worldwide.
- **Community**: Largest ecosystem of partners, tutorials, and third-party tools.
- **Innovation**: Constantly releasing new services (AI/ML, IoT, Satellite).

## Best For
- Enterprise-scale applications.
- Complex multi-region architectures.
- Organizations that want the widest selection of tools.
