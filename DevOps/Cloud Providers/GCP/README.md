# Google Cloud Platform (GCP)

## Overview
GCP is a suite of cloud computing services that runs on the same infrastructure that Google uses internally for its end-user products, such as Google Search and YouTube.

## Core Services Cheat Sheet

| Category | Service | Description |
| :--- | :--- | :--- |
| **Compute** | **Compute Engine** | Virtual machines (GCE). |
| | **Cloud Run** | Fully managed serverless containers (The industry favorite). |
| | **App Engine** | Platform-as-a-Service (PaaS) for app hosting. |
| **Containers** | **GKE** | Google Kubernetes Engine (The best K8s experience). |
| **Storage** | **Cloud Storage** | Unified object storage (GCS). |
| | **Filestore** | Managed NFS storage. |
| **Database** | **Cloud SQL** | Managed MySQL, PostgreSQL, and SQL Server. |
| | **Bigtable** | High-performance NoSQL for large scale. |
| | **Firestore** | Document NoSQL for web/mobile (Firebase). |
| **Data/AI** | **BigQuery** | Serverless, highly scalable data warehouse. |
| | **Vertex AI** | Unified platform for AI and Machine Learning. |
| **Networking** | **VPC** | Global VPC (easier networking than AWS). |
| | **Cloud Load Balancing** | High-performance, global load balancing. |
| **Identity** | **Cloud IAM** | Fine-grained resource access. |

## Why GCP?
- **Data & AI**: Unmatched tools for big data analytics (BigQuery) and machine learning.
- **Kubernetes**: Google invented K8s; GKE is the most stable and easiest to use.
- **Global Network**: One of the fastest private networks in the world.
- **Pricing**: Often more transparent and simpler than AWS.

## Best For
- Big data and analytics workloads.
- Kubernetes-heavy architectures.
- Organizations wanting the best developer experience (DX).
