# Code Quality & Security

## Overview
Tools to ensure your code is clean, bug-free, and secure from vulnerabilities.

## Tools in this Category
- **[SonarQube](./SonarQube/)**: Static application security testing (SAST).
- **[Snyk](./Snyk/)**: Vulnerability scanning for code and dependencies.
- **[Trivy](./Trivy/)**: Container and IaC scanner.
- **[k6](./k6/)**: Load testing as code.
- **[Falco](./Falco/)**: K8s runtime security.
- **[OPA / Kyverno](./Policy%20as%20Code/)**: Policy as Code for clusters.
