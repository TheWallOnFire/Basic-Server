# CI/CD Platforms

## Overview
Continuous Integration and Continuous Deployment (CI/CD) platforms automate the building, testing, and deployment of your software.

## Tools in this Category
- **[Jenkins](./Jenkins/)**: The classic, self-hosted automation server.
- **[GitHub Actions](./GitHub%20Actions/)**: Native automation for GitHub projects.
- **[GitLab CI](./GitLab%20CI/)**: Built-in CI/CD for GitLab.
- **[CircleCI](./CircleCI/)**: Cloud-native CI/CD service.
- **[ArgoCD](./ArgoCD/)**: GitOps CD for Kubernetes.
- **[FluxCD](./FluxCD/)**: Kubernetes-native GitOps controller.

## Choosing a Platform
- **GitHub Actions**: Best if your code is on GitHub.
- **GitLab CI**: Best for GitLab users.
- **ArgoCD**: Best for GitOps on Kubernetes.
- **Jenkins**: Best for complex, non-cloud-native, or strictly on-premise pipelines.
