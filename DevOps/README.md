# DevOps & Infrastructure Roadmap

This pillar focuses on the automation, delivery, and reliability of your applications. It follows the industry-standard [roadmap.sh/devops](https://roadmap.sh/devops) curriculum.

## 🗺️ Roadmap Sections

### 1. [Master Strategy](./docs/4_master_strategy.md)
The high-level methodologies: Deployment strategies (Canary, Blue/Green), Git branching, and Incident Response.

### 2. [OS & Terminal](./OS%20&%20Terminal/)
Linux fundamentals, Bash scripting, and power tools like Vim, Tmux, and systemd.

### 3. [Networking & Security](./Networking%20&%20Security/)
SSH, SSL/TLS, DNS, and modern edge protection with Cloudflare and Cilium.

### 4. [CI/CD & GitOps](./CI-CD%20Platforms/)
Jenkins, GitHub Actions, and Kubernetes native GitOps with ArgoCD and FluxCD.

### 5. [Infrastructure Provisioning](./Infrastructure%20Provisioning/)
Managing cloud resources as code with Terraform, Terragrunt, Pulumi, and AWS CDK.

### 6. [Containerization & Orchestration](./Orchestration/)
Docker, Kubernetes, Nomad, Helm, and Kustomize.

### 7. [Observability](./Observability/)
The four pillars of observability: Metrics (Prometheus), Logs (Loki), Traces (Jaeger), and Error Tracking (Sentry).

### 8. [Code Quality & Security](./Code%20Quality%20&%20Security/)
Static analysis (SonarQube), vulnerability scanning (Snyk, Trivy), and runtime security (Falco).
