# Containerization & Orchestration

## Overview
Containerization allows you to package your application and its dependencies into a single image. Orchestration manages the deployment and scaling of those containers across a cluster.

## Tools in this Category
- **[Docker](./Containerization/Docker/)**: The industry-standard container platform.
- **[Buildpacks](./Containerization/Buildpacks/)**: Automatic image creation without Dockerfiles.
- **[Kubernetes](./Orchestration/Kubernetes/)**: The most popular container orchestrator.
- **[Nomad](./Orchestration/Nomad/)**: Lightweight orchestrator by HashiCorp.
- **[Helm](./Orchestration/Helm/)**: Package manager for Kubernetes.
- **[Kustomize](./Orchestration/Kustomize/)**: Template-free customization for K8s.
