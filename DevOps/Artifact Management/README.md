# Artifact Management

## Overview
Repositories for storing and managing your built software artifacts (Docker images, NPM packages, Maven JARs).

## Tools in this Category
- **[JFrog Artifactory](./JFrog%20Artifactory/)**: Universal artifact repository.
- **[Harbor](./Harbor/)**: Private, secure cloud-native registry.
- **[Sonatype Nexus](./Sonatype%20Nexus/)**: Popular alternative for binary repository management.
