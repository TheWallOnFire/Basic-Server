# Server Projects & Frameworks

This folder contains backend implementations and message broker configurations across various languages.

## 🗄️ Languages & Frameworks
- **[Node.js](./Node.js/)**: The primary focus of this kit, featuring multiple frameworks (Express, NestJS, Fastify) and a deep ecosystem of utilities.
- **[Python](./Python/)**: High-performance backends using FastAPI and Flask, plus Celery for background tasks.
- **[Go](./Go/)**: Efficient, compiled servers using Gin and Echo.
- **[Rust](./Rust/)**: Memory-safe, high-speed servers using Actix and Rocket.
- **[Java](./Java/)**: Enterprise-grade backends with Spring Boot.
- **[PHP](./PHP/)**: Web-standard servers with Laravel.
- **[C#](./C%23/)**: Robust backends with ASP.NET Core.
- **[Ruby](./Ruby/)**: Developer-friendly servers with Ruby on Rails.

## 📨 Messaging & Real-time
- **[Message Brokers](./Message%20Brokers/)**: Kafka and RabbitMQ configurations.
- **[Socket.IO](./Node.js/Real-time/)**: Real-time WebSocket communication examples.
