# Ruby Server Ecosystem

## Overview
A dynamic, open-source programming language with a focus on simplicity and productivity. It has an elegant syntax that is natural to read and easy to write.

## Frameworks in this Category
- **[Ruby on Rails](./Ruby%20on%20Rails/)**: A model-view-controller (MVC) framework, providing default structures for a database, a web service, and web pages.
- **[Sinatra](./Sinatra/)**: A DSL for quickly creating web applications in Ruby with minimal effort.

## Key Features
- **Convention over Configuration**: Rails makes assumptions about what every developer needs to get started.
- **Gems**: A powerful package management system (RubyGems).
- **Active Record**: One of the most famous ORM implementations.
