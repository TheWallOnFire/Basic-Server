# 🗺️ ASP.NET Core Developer Roadmap

Welcome to the ASP.NET Core Roadmap! This guide is based on the [roadmap.sh/aspnet-core](https://roadmap.sh/aspnet-core) and is designed to take you from C# foundations to advanced microservices architecture.

1. **[C# Fundamentals](./01_csharp_foundations.md)**: Syntax, Types, LINQ, and OOP.
2. **[Web Basics](./01a_web_fundamentals.md)**: HTTP/HTTPS, REST, and JSON.

### 🟡 Phase 2: ASP.NET Core Basics

## 🚀 Pro Tip
Don't just learn the syntax. Understand **Dependency Injection (DI)** and **Middleware** early on — they are the "magic" that makes ASP.NET Core so powerful and flexible.
