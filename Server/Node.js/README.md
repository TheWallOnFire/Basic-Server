# Node.js Server Ecosystem

## Overview
Node.js is a cross-platform, open-source JavaScript runtime environment that can run on Windows, Linux, Unix, macOS, and more. it is the industry standard for high-performance, real-time web applications.

- **[Authentication](./Authentication/)**: Passport, JWT, bcrypt.
- **[Validation & Schema](./Validation%20&%20Schema/)**: Zod, Joi.
- **[Testing](./Testing/)**: Jest, Vitest, Supertest.
- **[API Tools](./API%20Tools/)**: Swagger, tRPC, GraphQL.
- **[Logging & Process](./Logging%20&%20Process/)**: Winston, PM2.
- **[Real-time](./Real-time/)**: Socket.IO.
