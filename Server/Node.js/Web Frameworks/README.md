# Node.js Web Frameworks

## Overview
Node.js has a diverse ecosystem of web frameworks, ranging from minimal libraries to full-stack enterprise solutions.

## Frameworks in this Category
- **[Express](./Express/)**: The "OG" of Node.js frameworks. Minimal, unopinionated, and has the largest ecosystem.
- **[NestJS](./NestJS/)**: A progressive Node.js framework for building efficient, reliable, and scalable server-side applications (Angular-inspired).
- **[Fastify](./Fastify/)**: Focused on providing the best developer experience with the least overhead and a powerful plugin architecture.
- **[Koa](./Koa/)**: Created by the team behind Express, aiming to be a smaller, more expressive, and more robust foundation for web applications.
- **[Hapi](./Hapi/)**: A rich framework for building applications and services with a focus on security and maintainability.

## Comparison Table
| Feature | Express | Fastify | NestJS |
| :--- | :--- | :--- | :--- |
| **Philosophy** | Unopinionated | Performance | Opinionated (OOP/DI) |
| **Speed** | Moderate | Very High | Moderate |
| **Typescript** | Via @types | Native | Native (First-class) |
| **Architecture** | Middleware-based | Hook-based | Controller/Service/Module |
