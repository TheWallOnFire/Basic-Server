# Node.js Validation & Schema

## Overview
Validation ensures that the data your application receives is in the correct format and contains the expected values. Schema definitions allow you to describe your data structures for type safety and documentation.

## Tools in this Category
- **[Zod](./Zod/)**: TypeScript-first schema declaration and validation library. It is the modern standard for Type-safe validation.
- **[Joi](./Joi/)**: A powerful schema description language and data validator for JavaScript.

## Comparison
| Feature | Zod | Joi |
| :--- | :--- | :--- |
| **Type Inference** | ✅ Automatic | ❌ Manual |
| **Syntax** | Functional/Fluent | Declarative |
| **Ecoystem** | Growing fast (tRPC, Prisma) | Mature |
| **Bundle Size** | Small | Moderate |
