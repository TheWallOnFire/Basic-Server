# Node.js Testing Ecosystem

## Overview
Testing is critical for maintaining high-quality code and preventing regressions.

## Tools in this Category
- **[Jest](./Jest/)**: The most popular testing framework with everything included (runner, assertion library, mocks).
- **[Vitest](./Vitest/)**: A Vite-native testing framework. Fast and compatible with Jest's API.
- **[Supertest](./Supertest/)**: A library for testing Node.js HTTP servers using a fluent API.

## Testing Strategy
- **Unit Tests**: Testing individual functions in isolation (Jest/Vitest).
- **Integration Tests**: Testing how different parts of the system work together.
- **E2E Tests**: Testing the full request-response cycle (Supertest + Jest).
