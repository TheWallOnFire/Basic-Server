# 11. Certifications & Resources

The cyber security field is vast, and certifications can help validate your knowledge.

## 1. Entry Level Certs
- **CompTIA Security+**: The foundational cert for most security roles.
- **Cisco CCNA**: For networking focused roles.
- **ISC2 CC**: Certified in Cybersecurity.

## 2. Professional Level
- **OSCP**: Offensive Security Certified Professional (The gold standard for pen testing).
- **CISSP**: Certified Information Systems Security Professional (Management focused).
- **CEH**: Certified Ethical Hacker.

## 3. Top Resources
- **TryHackMe**: Gamified, hands-on learning labs.
- **Hack The Box**: Advanced penetration testing labs.
- **Cyber-range**: Real-world simulation environments.
- **Darknet Diaries**: A fantastic podcast about real-world hacks.
