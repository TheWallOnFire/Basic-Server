# 04. Virtualization

Virtualization allows security professionals to build isolated labs, test malware, and run multiple systems on a single machine.

## 1. Hypervisors
- **Type 1 (Bare Metal)**: ESXi, Proxmox, Hyper-V.
- **Type 2 (Hosted)**: VirtualBox, VMware Workstation, UTM.

## 2. Containers
- **Docker**: Lightweight isolation for applications.
- **Kubernetes**: Orchestrating containers at scale.
- **Security Implications**: Escaping containers and misconfigurations.

## 3. Lab Setup
- Building a "Pwnbox" or attack machine (Kali, Parrot OS).
- Setting up vulnerable targets (Metasploitable, Windows VMs).
- Networking VMs for safe testing.
