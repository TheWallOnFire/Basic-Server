# 07. Cryptography

Cryptography is the art of protecting information through encryption.

## 1. Hashing vs. Encryption
- **Hashing (One-way)**: SHA-256, MD5 (broken), bcrypt. Used for passwords.
- **Encryption (Two-way)**:
    - **Symmetric**: Same key for both (AES, ChaCha20).
    - **Asymmetric**: Public/Private key pair (RSA, Elliptic Curve).

## 2. Digital Signatures
Ensuring authenticity and non-repudiation.

## 3. PKI (Public Key Infrastructure)
- Certificates (SSL/TLS).
- Certificate Authorities (CAs).
- Chain of Trust.
