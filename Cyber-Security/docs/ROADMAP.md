# 🗺️ Cyber Security Roadmap

Welcome to the Cyber Security Roadmap! This guide is based on the [roadmap.sh/cyber-security](https://roadmap.sh/cyber-security) and is designed to take you from IT fundamentals to advanced security professional.

---

## 🛤️ The Path

### 🟢 Phase 1: The Foundations
1. **[Fundamental IT Skills](./01_fundamental_it_skills.md)**: Hardware, Troubleshooting, and basic Networking.
2. **[Operating Systems](./02_operating_systems.md)**: Linux terminal mastery and Windows/Active Directory security.
3. **[Networking Knowledge](./03_networking_knowledge.md)**: OSI model, IP addressing, and critical protocols.
4. **[Virtualization](./04_virtualization.md)**: Lab setup with Hypervisors and Containers (Docker).

### 🟡 Phase 2: Security Core
5. **[Security Foundations](./05_security_foundations.md)**: CIA Triad, Defense in Depth, and Zero Trust.
6. **[Tools & Discovery](./06_tools_and_discovery.md)**: Nmap, Wireshark, and security-focused OS (Kali).
7. **[Cryptography](./07_cryptography.md)**: Hashing, Symmetric vs Asymmetric encryption, and PKI.

### 🟠 Phase 3: Strategy & Attacks
8. **[Frameworks & Compliance](./08_frameworks_and_compliance.md)**: NIST, ATT&CK, OWASP, and Risk Management.
9. **[Attack Vectors](./09_attack_vectors.md)**: Social Engineering, Web attacks, and Malware analysis.

### 🔴 Phase 4: Modern Sec & Career
10. **[Cloud & Programming](./10_cloud_and_programming.md)**: Cloud security models and Python for automation.
11. **[Certifications & Resources](./11_certifications_and_resources.md)**: Career paths (Sec+, OSCP, CISSP) and learning platforms.

---

## 🚀 Pro Tip
Cyber security is a "hands-on" field. Don't just read these docs—set up a virtual lab using **VirtualBox** and try the tools yourself in a safe environment!
