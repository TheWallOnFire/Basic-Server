# 05. Security Foundations

The core principles that guide every security decision.

## 1. The CIA Triad
- **Confidentiality**: Ensuring data is only seen by those authorized.
- **Integrity**: Ensuring data hasn't been tampered with.
- **Availability**: Ensuring systems are accessible when needed.

## 2. Key Concepts
- **Defense in Depth**: Layered security (Firewalls -> Antivirus -> Encryption).
- **Least Privilege**: Users only get the permissions they need.
- **Zero Trust**: "Never trust, always verify" - even inside the network.
- **Attack Surface**: The sum of all points where an attacker can try to enter.

## 3. Threat Actors
- Script Kiddies, Hacktivists, Cybercriminals, and State-Sponsored Actors (APTs).
