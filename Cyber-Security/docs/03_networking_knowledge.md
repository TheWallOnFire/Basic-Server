# 03. Networking Knowledge

Networking is the foundation of cyber security. You can't protect what you don't understand.

## 1. The OSI Model
1. **Physical**: Cables, bits.
2. **Data Link**: MAC addresses, switches.
3. **Network**: IP addresses, routers.
4. **Transport**: TCP/UDP, ports.
5. **Session**: Session management.
6. **Presentation**: Data formatting, encryption.
7. **Application**: HTTP, DNS, SMTP.

## 2. IP Addressing
- **IPv4 vs. IPv6**.
- **Subnetting**: Dividing networks for security and efficiency.
- **DHCP & DNS**: How devices get addresses and names.

## 3. Protocols
- **HTTP/S**: Web traffic.
- **SSH**: Secure remote access.
- **FTP/SFTP**: File transfer.
- **ICMP**: Diagnostic messages (ping).
