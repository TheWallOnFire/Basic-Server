# 09. Attack Vectors

Understanding how attackers think is the only way to defend effectively.

## 1. Social Engineering
- **Phishing**: Email-based deception.
- **Vishing/Smishing**: Voice/SMS based.
- **Tailgating**: Physical unauthorized entry.

## 2. Web Attacks
- **SQL Injection**: Manipulating database queries.
- **XSS (Cross-Site Scripting)**: Injecting malicious scripts into web pages.
- **CSRF**: Forcing a user to perform unwanted actions.

## 3. Malware
- Viruses, Worms, Trojans, Ransomware, and Spyware.
- Persistence mechanisms.
