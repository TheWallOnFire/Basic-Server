# 02. Operating Systems

A security professional must be comfortable with all major operating systems, as they are the primary targets and tools of the trade.

## 1. Linux (The Pro's Choice)
- **Filesystem**: Understanding `/etc`, `/var`, `/home`, and permissions.
- **Terminal**: Mastery of `bash`, `ssh`, `grep`, `awk`, and `sed`.
- **Package Management**: `apt`, `yum`, and compiling from source.

## 2. Windows
- **Active Directory**: The heart of enterprise security.
- **PowerShell**: Automation and incident response.
- **Registry & Event Viewer**: Investigating system changes.

## 3. MacOS
- Unix-based foundations.
- Security features (Gatekeeper, SIP).
