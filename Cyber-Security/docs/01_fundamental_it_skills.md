# 01. Fundamental IT Skills

Before diving into security, you must understand how computers and networks actually work.

## 1. Computer Hardware
- **CPU & RAM**: How processing and memory work.
- **Storage**: SSDs, HDDs, and how data is physically stored.
- **Motherboard & BIOS/UEFI**: The low-level software that starts the computer.

## 2. Troubleshooting
- Understanding the boot process.
- Identifying hardware vs. software failures.
- Using logs to diagnose system issues.

## 3. Basic Networking
- **NIC (Network Interface Card)**: The physical link.
- **Hubs, Switches, & Routers**: How data moves between devices.
- **Wired vs. Wireless**: Ethernet, Fiber, and Wi-Fi security basics.
