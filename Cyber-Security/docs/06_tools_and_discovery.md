# 06. Tools & Discovery

A security professional is only as good as their tools and their ability to interpret the results.

## 1. Reconnaissance & Discovery
- **Nmap**: The king of port scanners.
- **Shodan**: Search engine for internet-connected devices.
- **Whois & Dig**: Finding domain and DNS information.

## 2. Traffic Analysis
- **Wireshark**: Capturing and analyzing network packets.
- **Tcpdump**: Command-line packet sniffer.

## 3. Specialized OS
- **Kali Linux**: The industry standard penetration testing distro.
- **Tails**: For anonymity and privacy.
- **REMnux**: For reverse engineering and malware analysis.
