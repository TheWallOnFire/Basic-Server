# 10. Cloud & Programming

Modern security often happens in the cloud and requires some level of coding.

## 1. Cloud Security
- **Shared Responsibility Model**: What you protect vs. what the provider protects.
- **IAM (Identity & Access Management)**: Managing permissions in AWS/Azure/GCP.
- **S3 Bucket Security**: Preventing data leaks.

## 2. Programming for Security
- **Python**: The language of choice for security automation and scripting.
- **Bash/PowerShell**: Command-line automation.
- **Go/Rust**: Used for high-performance security tools and malware analysis.

## 3. Secure Coding
- Input validation.
- Secure session management.
- Avoiding hardcoded secrets.
